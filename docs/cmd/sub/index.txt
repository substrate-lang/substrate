cmd/sub/sub     sub, the command for programs, which bin/sub runs with every grant and the toolchain's directory first in its arguments.

;; ==== private ====

cmd/sub/build   Building a program: its package, module map and module check, the cache and the store, and the grants it narrows to.
cmd/sub/common  What sub's modules share: the toolchain's directory, the current directory, an arena, and small helpers.
cmd/sub/doc     sub doc: the documentation of packages and roots of the toolchain (compiler, host), written as text or HTML (std/doc), or one module, directory or item of one, printed by the name the compiler finds it by.
cmd/sub/fetch   Fetching the packages url dependencies pin into the store, one at a time, each unpacked by a worker that may read and write only its staging directory.
cmd/sub/site    Web sites and packs of files for a page's host.
