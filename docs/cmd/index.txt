cmd/serve  sub serve [-l ADDRESS] [-t CERT KEY] [-z LEVEL] DIR [PORT] serves DIR's files on ADDRESS (127.0.0.1) and PORT (8000), over TLS when given a certificate, gzipped at LEVEL (6; 0 for none).
cmd/sub/   sub, the command for programs, which bin/sub runs with every grant and the repository's directory first in its arguments.
