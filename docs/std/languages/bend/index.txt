;; std/languages/bend
;; Bend in one module: the language and Base.

std/languages/bend/base     A slice of Bend2's Base library: datatypes, equality, Nat, Bool, Cmp, words and U32.
std/languages/bend/bend     Bend in one module: the language and Base.
std/languages/bend/core     Bend's type checker: a function-for-function port of Bend2's type checker, bend.ts.
std/languages/bend/lang     Bend's forms: Bend2's dependently typed, affine language, in s-expressions.
std/languages/bend/lower    Bend's code generator: each checked definition as a wasm function over linear memory.
std/languages/bend/runtime  The runtime of Bend's compiled code: nodes, reference counting and printing.
