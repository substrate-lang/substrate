;; std/package

std/package/files     A package's files: the modules it exports, name.sub and those its (exports ...) names, and the files they reach through the requires their source writes, by a path or by the package's name, found as the compiler finds them.
std/package/hash      A package's hash: the SHA-256 of a line for each of its files (files.sub) and package.sub, in path order, of the file's SHA-256 in hex, two spaces and its path, then a line for each of its dependencies, in its manifest's order, of the dependency's hash, two spaces and its name; written sha256:hex.
std/package/manifest  Manifests: a package's package.sub, or a program's first form, (package name (version "major.minor.patch") (exports module ...) (dependencies (name (path "directory") (hash "sha256:hex")) (name (url "address") (hash "sha256:hex")) ...)), the exports, the dependencies and a path's hash being optional.
std/package/map       The module map the compiler takes for a program in a package: a root for the package and for each package its dependencies reach, with the names each uses, and each package's exports and files for sub's module check; and std, a name every module has, the std a package depends on or else the package at std.
std/package/path      Paths, as the package library and sub use them.
std/package/read      Data in Substrate's syntax, as package.sub holds it: lists in ( ) or [ ], symbols and strings, with the comments and string escapes of Substrate's reader, read into an arena.
std/package/store     The store: the packages url dependencies pin, each in a directory named by its hash, holding just the files the hash covers.
