;; std/encoding

std/encoding/base64  Base64 (RFC 4648), with padding, and base64url, its URL and file name alphabet without padding.
std/encoding/json    JSON (RFC 8259): values after cJSON's, in an arena; a token reader after Go's Decoder.Token; writing as JavaScript's JSON.stringify writes, but -0 as -0; and the json form, a type's writer and reader after serde's derive.
std/encoding/utf8    UTF-8 (RFC 3629).
std/encoding/wire    Wire messages, encoded in the postcard 1.x wire format (postcard.jamesmunns.com/wire-format).
