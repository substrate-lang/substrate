;; std/http/route
;; Routes after Go's ServeMux, written as s-expressions with typed parameters. (routes name [METHOD (segment ...)
;; handler option ...] ...) defines name, a handler for http-serve!. A segment is a string; [name type], of type string
;; or an integer type; or, last, [name string ...], the rest of the path. "" last is the empty segment after a final
;; slash. The handler gets the request, the parameters, then a pointer to what (query T) reads, then a pointer to what
;; (json T) or (form T) reads or the bytes (body) reads; (limit n) bounds the body. The most specific route wins, and
;; routes that overlap with neither more specific are refused. A handler's first route defines handler.url!.
;; requires std/http/http std/http/server std/http/url std/http/multipart std/http/form std/encoding/json compiler/macros

;; ---- code ----

(define-syntax routes)
