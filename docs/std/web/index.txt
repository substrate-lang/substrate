;; std/web
;; The language of a web page's program: Substrate, ui.sub's views, and app: model, messages, update, view.

std/web/canvas     Drawing on a <canvas> element: rectangles, paths, circles and text.
std/web/gpu        WebGPU from a program: the program's side of the host module "gpu".
std/web/html       HTML text: characters escaped for a page's text, and for an attribute's value too when attribute is set.
std/web/pack       Packs of files for a page's host, which subhost-web.mjs unpacks: each file's name and bytes follow their lengths as little-endian u32s, in name order.
std/web/trace      A test helper: prints the page changes (patches) that views produce, as text.
std/web/ui         Views: a small language for describing web pages, compiled to patches.
std/web/web        The language of a web page's program: Substrate, ui.sub's views, and app: model, messages, update, view.
std/web/examples/
std/web/game/      The game loop: what turns three functions into a game in a web page.
std/web/repl/      The REPL web page: the half the user sees.
std/web/scene/     A 3D scene drawn by the GPU: meshes lit by a sun, under a sky, made into a picture.
std/web/shade/     Shade's shade-library form, which shares definitions between shaders.
