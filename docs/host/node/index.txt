;; host/node

host/node/env      Environment variables: the host module "env".
host/node/net      TCP: the host module "net", whose connections are streams.
host/node/process  Child programs: the host module "process", whose pipes are streams.
host/node/signal   Signals to the program: the host module "signal", after Deno's addSignalListener.
host/node/stdin    Standard input: the host module "stdin", one stream.
host/node/watch    Watching files: the host module "watch", after Deno's watchFs.
