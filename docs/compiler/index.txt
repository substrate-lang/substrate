;; compiler

compiler/binary     The binary wasm encoder and assembler.
compiler/checker    The checker: checks Substrate code's types, lays out its data and lowers it for the back end.
compiler/compile    The back end: a module's lowered code to wasm bytes.
compiler/core       The records the expander and the back end share.
compiler/expander   The expander: syntax to lowered code, with modules, the cache and sessions.
compiler/leb128     LEB128 integers, written into buffers.
compiler/link       Wasm modules from C: a dynamic-linking side module (clang -shared, Emscripten's side modules) rewritten into the form of a program's modules, on the prelude's memory, table, stack and allocator.
compiler/macros     The macro tools: syntax-match, quasiquote, quasisyntax, for/each, for/list, for/fold, fmt and define-macro.
compiler/main       The compiler's command line, which builds the compiler and sub, cmd/sub/sub.sub: build, expand and eval.
compiler/ops        The wasm numeric and memory instructions.
compiler/prune      The pruner removes the functions a program can never call, imported ones among them, and renumbers the rest.
compiler/reader     The reader: source text to syntax objects, with locations and no scopes.
compiler/running    Reads wasm modules: the running compiler's, and a program's for the pruner.
compiler/serialize  The serializer: data as bytes, in the format syntax.sub's deserialize reads.
compiler/substrate  Substrate in one module: the language, its runtime and its library.
compiler/syntax     The syntax module: the data every language shares, and the macro contract.
compiler/wasm       Wasm's own forms and instructions, written wasm:name after (require wasm "wasm.sub").
compiler/writer     Characters into a buffer, as the reader reads them.
